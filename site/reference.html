Slash commands

Typed at the prompt inside a session. Tab completes a command or its argument for the ones that take one (/resume, /model, /forget, /undo, /open, /diff); a partial name matches on its letters in order, so /rsm finds /resume. Aliases: /? for /help, /exit and /q for /quit, /new for /clear, /perms for /permissions, /ctx for /context, /todo for /todos, /i for /inspect, /search for /find, /sessions for /resume, /cost for /usage.

Command-line flags

janetcode [flags] [prompt] starts an interactive session; janetcode -p "prompt" [flags] runs one prompt headless and exits. Flags for evals (--eval and the rest) are on the evals feature entry and in docs/manual/evals.md.

--output-format text|json|stream-jsonwith -p: how the run reports itself
--max-cost <usd>with -p: stop once the run has spent this much, and exit 55. Checked after every model call, so a long turn stops within one call of the ceiling; a model nothing can price is not held to it
--max-turns <n>cap the model calls one turn may make; the eval runner's --eval-max-turns with the everyday spelling, so a benchmark can give a headless run and an eval run the same budget

--theme <name>colour theme for this run: auto, dark, light, or a builtin or user theme name. Overrides the config for this run only; --inspect themes lists them

--sandboxwrap local bash in docker (or sandbox-exec on macOS). File tools stay on the workspace host. Off by default; /sandbox toggles it
--auto-editsauto-accept file edits; commands still ask. /edits toggles the same thing mid-session

--until "<cmd>"keep going until the command exits 0, at most five rounds

--webserve the session in a browser instead of the terminal

Output formats (--output-format, with -p)

text (default) prints the assistant's answer on stdout and everything else on stderr, unchanged. json prints one result object at the end, with fields including result, is_error, exit_code, session_id, usage (token counts), cost_usd and cost_source (reported, list price or unpriced), num_turns, tool_calls, verdict, duration_ms, a recoveries object (rescues the harness had to make: prose read back as tool calls, stalled streams killed, model fallbacks used) and retries (model calls that failed transiently and then succeeded). stream-json prints the same events as newline-delimited JSON as they happen, ending with the same result object as its last line.

Exit codes

Process exit codes
CodeMeaning
0the run finished
1anything else
41no API key, or the endpoint rejected it (HTTP 401/403)
42the flags or the prompt do not make sense
52the configuration file cannot be used
53the turn hit its model-call cap
55the run reached --max-cost
130interrupted, as a shell reports a SIGINT

The code is also in the exit_code field of the --output-format json result object, so a caller reading only stdout still has it.

Tools the model can call

These are the built-in tools available inside a normal session (an eval run or a --what-if live run uses a smaller, fixed subset). All paths are confined to the working directory, symlinks included. Read-only tools run concurrently; mutating tools run one at a time, in the order the model called them.

Configuration keys

Precedence is command-line flags, then environment variables, then the config file. janetcode --init writes a starter file at ~/.config/janetcode/config.json (honouring XDG_CONFIG_HOME).

{
  "provider": "anthropic",
  "model": "claude-opus-5",
  "max_tokens": 16000,
  "effort": "high",
  "auto_approve": false,
  "max_iterations": 50,
  "compact_at": 80000,
  "memory": true,
  "hints": true,
  "proof_notes": true,
  "theme": "auto",
  "providers": {
    "anthropic":  { "type": "anthropic", "api_key": "sk-ant-..." },
    "openrouter": { "type": "openai", "base_url": "https://openrouter.ai/api/v1",
                    "api_key": "sk-or-1", "api_keys": ["sk-or-2"], "model": "deepseek/deepseek-v4-flash" },
    "ollama":     { "type": "openai", "base_url": "http://localhost:11434/v1" }
  }
}

Environment variables always win over the config file's own stored values but lose to command-line flags; a key from the environment is never written back into the config file.
