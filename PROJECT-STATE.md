## Key Decisions
- Go + bubbletea; product name is janetcode, not the Janet language (2026-09-07).
- Anthropic via official SDK per policy; OpenAI-compatible hand-rolled to tolerate dialects (Qwen, DeepSeek, vLLM, Ollama, OpenRouter) and learn quirks from 400s at runtime (2026-09-07).
- Compaction instead of in-place history pruning: Fable 5.1 preserved-thinking rejects edited history, so the harness is append-only and compaction starts a fresh history (2026-09-07).
- Tool results for a turn always go back in one user message; history stays provider-valid on every return path, including cancellation (2026-09-07).
- Sessions rotate to a new file when history shrinks so pre-compaction transcripts are never overwritten (2026-09-07).

## Architecture Notes
- `internal/llm` is the provider-neutral core: Message/Block, ToolDef, Request, Event, Provider.Stream(ctx, req, emit) → Response.
- `internal/agent.Agent.Run` is the loop; `Approver` is the permission hook; `EstimateTokens`/`Compact` handle context size.
- TUI never touches agent state while a turn runs; the agent goroutine sends `agentEventMsg`/`agentDoneMsg`/`permissionMsg` through `model.send`.
- Terminal background is detected once before the program starts (`lipgloss.HasDarkBackground`); creating glamour renderers with AutoStyle later would re-query the terminal and eat keystrokes.
- Rendering cost: glamour takes ~95 ms per 2 KB and ~0.9 s per 20 KB, so the transcript renders markdown per blank-line-separated block with a per-entry cache (only the streaming tail re-renders), agent events are coalesced through `eventQueue` so rendering never blocks the model stream, and `refresh` skips `viewport.SetContent` when the content string is unchanged. Regression guard: `TestStreamingLargeAnswerStaysResponsive`.
- TUI interaction features (all tested in `internal/tui/tui_test.go`): queued prompts while running, `@path` attachments with tab completion (`internal/prompt/mentions.go`), deny-with-reason via `agent.ReasonApprover`, `!command` passthrough that feeds `Agent.AddContext`, `/resume` picker, custom commands from `.janetcode/commands/*.md` (`internal/prompt/commands.go`), `fetch_url` tool. Second round added: cost (provider-reported or `prices` table), `/find`, `/undo` (per-turn snapshots via `tool.Toucher`, `internal/agent/undo.go`), `@image.png` as image blocks on both providers, `task` subagent tool (`internal/agent/task.go`), and MCP over stdio (`internal/mcp`: client, tool adapter, manager, `.mcp.json` trust store; `/mcp`). Third round: undo checkpoints persisted next to the session (`<id>.undo.json`), ctrl+v clipboard image paste (`internal/tui/clipboard.go`), MCP remote servers (`internal/mcp/http.go`: Streamable HTTP with legacy SSE fallback, `url`/`headers` config), MCP resources as synthetic tools and prompts as `/mcp__server__prompt` commands. Fourth round: completion menus navigable with ↑↓, `config.Providers` map (named entries, presets in `internal/config/providers.go`, `api_keys` rotated by both providers on 429/401/403, per-entry last model, `config.Update` rewrites only the provider keys of the file and never persists env keys), `/connect` and `/model` dialogs (`internal/tui/connect.go`: centred modal with its own search field, provider → URL → masked keys → async `ListModels`, `truncateLine` is width-aware via x/ansi), keyless OpenAI-compatible local servers.
- Testing a TUI under a real pty: `scratchpad/smoke/drive.py` pattern — reply to OSC 11 (`\e]11;rgb:…\e\\`) and DSR (`\e[1;1R`) or bubbletea/termenv blocks for 5 s.
