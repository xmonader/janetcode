## Key Decisions
- Go + bubbletea; product name is janetcode, not the Janet language (2026-09-07).
- Anthropic via official SDK per policy; OpenAI-compatible hand-rolled to tolerate dialects (Qwen, DeepSeek, vLLM, Ollama, OpenRouter) and learn quirks from 400s at runtime (2026-09-07).

Amended 2026-09-08: `Agent.Prune` rewrites only the *text of old tool_result blocks* (superseded reads stubbed, long outputs trimmed) and only on the way to compaction; thinking blocks and their signatures are never touched. Compaction now keeps the recent tail (≤6 messages, ≤12k tokens) verbatim after the summary.
- Tool results for a turn always go back in one user message; history stays provider-valid on every return path, including cancellation (2026-09-07).
- Sessions rotate to a new file when history shrinks so pre-compaction transcripts are never overwritten (2026-09-07).

## Architecture Notes
- `internal/llm` is the provider-neutral core: Message/Block, ToolDef, Request, Event, Provider.Stream(ctx, req, emit) → Response.
- `internal/agent.Agent.Run` is the loop; `Approver` is the permission hook; `EstimateTokens`/`Compact` handle context size.
- TUI never touches agent state while a turn runs; the agent goroutine pushes events into `eventQueue` (drained on `flushMsg`) and sends `agentDoneMsg`/`permissionMsg`/`askMsg` through `model.send`.
- Terminal background is detected once before the program starts (`lipgloss.HasDarkBackground`); creating glamour renderers with AutoStyle later would re-query the terminal and eat keystrokes.
- Rendering cost: glamour takes ~95 ms per 2 KB and ~0.9 s per 20 KB, so the transcript renders markdown per blank-line-separated block with a per-entry cache (only the streaming tail re-renders), agent events are coalesced through `eventQueue` so rendering never blocks the model stream, and `refresh` skips `viewport.SetContent` when the content string is unchanged. Regression guard: `TestStreamingLargeAnswerStaysResponsive`.
